# 订阅与提醒规则

## 到券提醒是什么

当你关注的券还没有开始抢购时，可以订阅「到券提醒」。平台会在活动开始前通过**延迟队列**投递提醒消息，支持短信和 App 两种通知渠道（由平台配置决定）。

## 订阅了为什么没收到提醒

可能的原因：

1. **订阅的是已开始的券**：活动已经开始时不再触发提醒
2. **通知渠道未开启**：平台的短信/App 通知有开关配置，未开启时只记录不发送
3. **延迟队列消息还在等待中**：提醒按活动开始时间倒计时投递，未到时间不会发

## 一个券可以重复订阅吗

可以取消后重新订阅。订阅状态是**按用户和券的唯一组合**维护的，重复订阅不会产生多条记录，取消也会同步清除。

## 订阅状态在哪看

券列表接口会批量返回每张券的订阅状态，前端据此显示「已订阅 / 订阅提醒」按钮。如果你看到状态和预期不一致，刷新页面重新拉取即可。
